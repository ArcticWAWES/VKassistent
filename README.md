# ИНСТРУКЦИЯ К БИБЛИОТЕКЕ VKassistent

   **VKassistent** — Кастомная библиотека для создания умных устройств
на базе микроконтроллеров с процессором ESP32, управляемых с помощью
чат-бота в социальной сети «ВКонтакте».

![Логотип VKassistent](VKassistent_logo.png)

   Библиотека позволяет принимать команды с помощью специально
создаваемых умных клавиатур или отдельно высылаемых сообщений,
а также принимать и отправлять вложения: фото, документы, гео-метки.

## НАСТРОЙКА СООБЩЕСТВА

   Для работы библиотеки вам потребуется **создать сообщество
ВКонтакте** с включённым внутри ботом. Именно от имени этого
сообщества ESP32 будет принимать и отправлять сообщения.

   Пошаговая инструкция от VK по созданию и настройке бота:
*https://dev.vk.com/ru/api/bots/getting-started*

**Основные шаги:**

1. Создайте сообщество: vk.com/groups → Создать сообщество → Тип:
   «Публичная страница» или «Группа».
2. В настройках сообщества: **Управление → Сообщения → Сообщения
   сообщества → Включены**.
3. Включите **Long Poll API**: **Управление → Работа с API →
   Long Poll API → Включено**.
4. В разделе **Long Poll API → Типы событий** отметьте:
   - ☑ **Входящие сообщения**
5. Создайте **токен доступа** (см. следующий раздел).
6. Убедитесь, что вы **подписаны** на своё сообщество.

## ПРАВА ТОКЕНА

> **ВАЖНО**
>
> Библиотека использует **токен сообщества** — для Long Poll
> и отправки сообщений.
>
> Для отправки своих фото (например, с ESP32-CAM) может потребоваться
> дополнительный токен — этот момент будет рассмотрен отдельно.

**Как создать токен сообщества:**

1. Управление → Дополнительно → Работа с API → Ключи доступа → Создать ключ.
2. Отметьте галочки:
   - ☑ **Сообщения сообщества** — для `messages.send`.
   - ☑ **Управление сообществом** — для Long Poll.
3. Скопируйте токен в переменную `Token`.

## НАСТРОЙКА И ПОДГОТОВКА ДАННЫХ

> **ПРЕДУПРЕЖДЕНИЕ**
>
> ДЛЯ РАБОТЫ ТРЕБУЕТСЯ СКАЧАТЬ ВСПОМОГАТЕЛЬНУЮ БИБЛИОТЕКУ ArduinoJson.h,
> Она может скачаться автоматически или предложить автоскачивание.

   В начале кода вы обязаны указать данные, нужные для подключения
к вашей сети под типом данных String:
- Название сети WiFi, куда будет подключаться устройство.
- Пароль от подключаемой сети WiFi.
- Токен вашего VK бота.
- ID вашей группы/сообщества, где находится бот.

Учтите, что название именно этих констант не должно отличаться, именно
они используются в файлах библиотеки, пример смотреть ниже.

``` cpp
String SSID     = "__________"; // имя сети
String PASSWORD = "__________"; // пароль сети
String Token    = "__________"; // токен сообщества
String GroupID  = "__________"; // айди группы
```

> **ПРЕДУПРЕЖДЕНИЕ**
>
> Убедитесь что ваша WiFi сеть работает на частоте 2.4 ГГц, ибо не все
> процессоры ESP32 могут работать на частоте 5 ГГц.

## РАБОТА С БОТОМ

   В `void setup()` нужно настроить скетч для верной работы бота.
Используем эти команды:
- `bot.connectWIFI(SSID, PASSWORD);` — подключение к вашей сети WiFi.
- `bot.begin();` — запуск VK бота (инициализация LittleFS + Long Poll).

``` cpp
void setup() {
  Serial.begin(115200); // важно сделать именно эту частоту

  bot.connectWIFI(SSID, PASSWORD);  // Подключаем Wi-Fi
  bot.begin();                      // Запускаем бота
  ...
}
```

   В `void loop()` обязательно должна быть команда `bot.loop();`.
Она опрашивает VK через Long Poll и обрабатывает входящие сообщения.

``` cpp
void loop() {
  bot.loop();
}
```

## ХРАНИЛИЩЕ

   По умолчанию библиотека использует **LittleFS** — внутреннюю память
ESP32 (~1.4 МБ). Это удобно как **буфер**: бот сохраняет файлы туда,
а вы в своём коде решаете, что с ними делать — хранить, копировать
на SD или отправлять дальше.

   Если нужно хранить **много** файлов — вызовите `useSD(csPin)`.
После этого все `savePhoto` / `sendPhotoFromFS` будут работать
с SD-картой. Параметр `fs` в методах указывать **не нужно**.

``` cpp
// По умолчанию — LittleFS (можно не вызывать)
bot.useLittleFS();

// Переключиться на SD-карту
bot.useSD(5);                    // CS = GPIO 5, остальные стандартные
bot.useSD(5, 18, 19, 23);        // CS, SCK, MISO, MOSI
```

## СОЗДАНИЕ КЛАВИАТУРЫ

   Для создания умной клавиатуры вызывается функция `createKeyboard`:

``` cpp
String menu = createKeyboard(
  Button("ВКЛЮЧИТЬ", positive),
  Button("ВЫКЛЮЧИТЬ", negative),
  Line(),
  Button("СТАТУС", primary),
  Button("НАСТРОЙКИ", secondary)
);
```

Где `menu` — название объекта клавиатуры, а `Button` — сама кнопка.
Она имеет два параметра: текст кнопки в «кавычках» и цвет кнопки.

**Разбор строк:**
- `"ВКЛЮЧИТЬ"` — **текст**, который увидит пользователь на кнопке.
- `positive` — **цвет** кнопки (см. список ниже).
- `Line()` — **перенос** на новую строку (без него кнопки идут
  по 5 в ряд).

VK поддерживает данные цвета кнопок:
- 🔵 **primary** — синий, для важных/основных действий.
- ⚪ **secondary** — белый, для стандартных/обычных действий.
- 🟢 **positive** — зелёный, для подтверждения/одобрения.
- 🔴 **negative** — красный, для удаления/предупреждения.

> **ПРЕДУПРЕЖДЕНИЕ**
>
> Цвета кнопок несут в себе чисто эстетическое значение.

   Функция `Line()` служит для переноса кнопок на новую строку. Если её
не использовать — кнопки автоматически разместятся по 5 в ряд.

   Пример без `Line()` — все кнопки в одном ряду:

``` cpp
String row = createKeyboard(
  Button("1"), Button("2"), Button("3")
);
// → [1][2][3] в одну строку
```

   Пример с `Line()` — перенос:

``` cpp
String menu = createKeyboard(
  Button("ВКЛ", positive),
  Button("ВЫКЛ", negative),
  Line(),
  Button("СТАТУС", primary)
);
// → [ВКЛ][ВЫКЛ]
//   [СТАТУС]
```

## РЕГИСТРАЦИЯ КОМАНД

   Библиотека предоставляет **три способа** регистрации команд.

### 1. Старый API — processMessage

Принимает два параметра: `long userId` и `String text`.

``` cpp
bot.processMessage("ВКЛЮЧИТЬ", [](long UserID, String text) {
  digitalWrite(LED_PIN, HIGH);
  bot.send(UserID, "🔛 Включено");
});
```

**Разбор строк:**
- `"ВКЛЮЧИТЬ"` — **текст команды**, который должен точно совпадать
  с сообщением от пользователя.
- `UserID` — **ID чата**, откуда пришла команда (используется для ответа).
- `text` — **текст полученного сообщения** (то же, что `"ВКЛЮЧИТЬ"`).
- `bot.send(UserID, "🔛 Включено")` — **отправка ответа** в тот же чат.

### 2. Новый API без параметров — onMessage

Короткий вариант для простых команд.

``` cpp
bot.onMessage("СТАТУС", []() {
  bot.sendToLast("📊 Система работает");
});
```

**Разбор строк:**
- `"СТАТУС"` — **текст команды**.
- `bot.sendToLast("...")` — **отправка ответа** в тот же чат, откуда
  пришла команда (не нужно указывать `peerId` вручную).

`sendToLast` — отправляет сообщение в тот же чат, откуда пришла команда.
**Работает только внутри колбэка.**

### 3. Новый API с VKMessage — onMessage

Полный вариант — доступ к `peerId`, `fromId`, `attachments`.

``` cpp
bot.onMessage("ID", [](VKMessage& msg) {
  String info = "Твой peerId: " + String(msg.peerId) +
                "\nТвой fromId: " + String(msg.fromId);
  bot.send(msg.peerId, info);
});
```

**Разбор строк:**
- `"ID"` — **текст команды**.
- `msg.peerId` — **ID чата**, куда нужно отвечать.
- `msg.fromId` — **ID пользователя**, который написал команду.
- `bot.send(msg.peerId, info)` — **отправка сообщения** с текстом `info`
  в чат `msg.peerId`.

> **ВАЖНО**
>
> Текст команды в «кавычках» должен **точно совпадать** с текстом на
> кнопке или сообщением, которое может написать пользователь.
> Регистр важен.

## ПРИЁМ ВЛОЖЕНИЙ

   Библиотека автоматически распознаёт вложения и вызывает
соответствующий обработчик.

### Фото — onPhoto

``` cpp
bot.onPhoto([](VKMessage& msg) {
  if (!msg.hasPhoto()) return;
  String url = msg.getPhotoUrl();
  Serial.println("📸 Фото: " + url);
  bot.send(msg.peerId, "✅ Фото принято");
});
```

**Разбор строк:**
- `msg.hasPhoto()` — **проверка**, есть ли в сообщении фото.
- `msg.getPhotoUrl()` — **URL фото** (максимальный размер).
- `bot.send(msg.peerId, "...")` — **ответ** в чат, откуда пришло фото.

### Документ — onDoc

``` cpp
bot.onDoc([](VKMessage& msg) {
  if (!msg.hasDoc()) return;
  String title = msg.getDocTitle();
  String url   = msg.getDocUrl();
  Serial.println("📄 Документ: " + title);
  bot.send(msg.peerId, "✅ Документ " + title + " принят");
});
```

**Разбор строк:**
- `msg.hasDoc()` — **проверка**, есть ли документ.
- `msg.getDocTitle()` — **имя файла** (например, `config.json`).
- `msg.getDocUrl()` — **ссылка** на документ (живёт ~1 час).
- `bot.send(msg.peerId, "...")` — **ответ**.

### Гео-метка — onGeo

``` cpp
bot.onGeo([](VKMessage& msg) {
  float lat = msg.getLat();
  float lon = msg.getLon();
  bot.send(msg.peerId, "📍 " + String(lat, 6) + ", " + String(lon, 6));
});
```

**Разбор строк:**
- `msg.getLat()` — **широта** (число с плавающей точкой).
- `msg.getLon()` — **долгота**.
- `String(lat, 6)` — **6 знаков после запятой** при выводе.

### Стикер — onSticker

``` cpp
bot.onSticker([](VKMessage& msg) {
  int id = msg.attachments[0].id;
  bot.send(msg.peerId, "🎨 Стикер id: " + String(id));
});
```

**Разбор строк:**
- `msg.attachments[0]` — **первое вложение** в сообщении.
- `.id` — **ID стикера** (число).
- `bot.send(msg.peerId, "...")` — **ответ**.

> **ПРЕДУПРЕЖДЕНИЕ**
>
> VK **не позволяет** ботам сообществ отправлять стикеры от своего имени.
> Принимать стикеры — можно, отправлять — нет.

## СОХРАНЕНИЕ ВЛОЖЕНИЙ В ПАМЯТЬ

   Библиотека умеет сохранять входящие фото и документы в файловую
систему (LittleFS по умолчанию, либо SD — если вызван `useSD`).

### Сохранить фото из сообщения

``` cpp
bot.onPhoto([](VKMessage& msg) {
  String path = bot.savePhoto(msg);
  if (path != "") {
    bot.send(msg.peerId, "✅ Сохранено: " + path);
  }
});
```

**Разбор строк:**
- `bot.savePhoto(msg)` — **сохраняет фото** из сообщения, возвращает
  **путь** (`/photo_12345_67890.jpg`) или пустую строку при ошибке.
- `path != ""` — **проверка**, что сохранение прошло успешно.
- `bot.send(msg.peerId, "...")` — **ответ** с путём к файлу.

### Сохранить фото и сразу ответить

``` cpp
bot.onPhoto([](VKMessage& msg) {
  bot.savePhotoAndReply(msg);
});
```

**Разбор строк:**
- `bot.savePhotoAndReply(msg)` — **сохраняет** фото и **автоматически
  отправляет** ответ в чат (`✅ Сохранено: <путь> (N байт)`).

### Сохранить документ

``` cpp
bot.onDoc([](VKMessage& msg) {
  bot.saveDocAndReply(msg);
});
```

**Разбор строк:**
- `bot.saveDocAndReply(msg)` — то же, но для документа.

> **ВАЖНО**
>
> При сохранении в LittleFS **все старые файлы удаляются** перед записью
> нового. Это сделано, чтобы не забивать память (1.4 МБ).
> На SD — файлы **не удаляются**, можно хранить много.

## ОТПРАВКА ФОТО

   Библиотека умеет отправлять фото **из файловой системы** (LittleFS
или SD — что сейчас активно).

### Отправить фото из памяти

``` cpp
bot.onMessage("отправь", [](VKMessage& msg) {
  bot.sendPhotoFromFS(msg.peerId, "📸 Вот фото:", "/photo.jpg");
});
```

**Разбор строк:**
- `msg.peerId` — **ID чата**, куда отправляем.
- `"📸 Вот фото:"` — **текст-подпись** к фото.
- `"/photo.jpg"` — **путь** к файлу внутри текущей FS.

> **ПРЕДУПРЕЖДЕНИЕ**
>
> Для отправки фото **обязательно** нужен пользовательский токен.
> Токен сообщества **не подойдёт** — VK вернёт `error_code: 15`.

bot.send(msg.peerId, "Hello_world!");

**Разбор строк:**
- `msg.peerId` — **ID чата**, куда отправляем.
- `"Hello_world!"` — **текст сообщения**.

bot.sendWithKeyboard(msg.peerId, "Выбери действие:", menu);

**Разбор строк:**

## АДМИНЫ

   Библиотека позволяет вести список администраторов — пользователей,
которым разрешено управлять ботом.

> **ВАЖНО**
>
> Админы — это **просто список**. Библиотека **не блокирует команды
> автоматически**. Проверку прав вы делаете сами в колбэках через
> `isAdmin()`.

   Заведите переменные для ID администраторов:

``` cpp
long MyID     = __________;   // ваш VK ID
long FriendID = __________;   // ID друга
```

   В `setup()` добавьте их в список:

``` cpp
bot.addAdmin(MyID);
bot.addAdmin(FriendID);
```

**Разбор строк:**
- `MyID`, `FriendID` — **ID пользователей**, которым разрешено
  управлять ботом.

   В колбэке проверяйте права:

``` cpp
bot.onMessage("ВЫКЛЮЧИТЬ", [](VKMessage& msg) {
  if (!bot.isAdmin(msg.fromId)) {
    bot.send(msg.peerId, "⛔ Нет прав");
    return;
  }
  digitalWrite(LED_PIN, LOW);
  bot.send(msg.peerId, "🔴 Выключено");
});
```

**Разбор строк:**
- `msg.fromId` — **ID того, кто написал** команду.
- `bot.isAdmin(msg.fromId)` — **проверка**, является ли он админом.
- `return` — **выход** из колбэка, если прав нет.

> **ВАЖНО**
>
> Без явной проверки `isAdmin()` команды выполняются **для всех
> пользователей**.

## ПОЛНЫЙ ПРИМЕР

``` cpp
#include <VKassistent.h>

String SSID     = "__________";
String PASSWORD = "__________";
String Token    = "__________";
String GroupID  = "__________";

VKassistent bot(Token, GroupID);

// Клавиатура главного меню
String mainMenu = createKeyboard(
  Button("ВКЛЮЧИТЬ", positive),
  Button("ВЫКЛЮЧИТЬ", negative),
  Line(),
  Button("СТАТУС", primary),
  Button("МЕНЮ", secondary)
);

void setup() {
  Serial.begin(115200);

  bot.connectWIFI(SSID, PASSWORD);
  bot.begin();

  // Приём фото — сохраняем
  bot.onPhoto([](VKMessage& msg) {
    bot.savePhotoAndReply(msg);
  });

  // Приём документа — сохраняем
  bot.onDoc([](VKMessage& msg) {
    bot.saveDocAndReply(msg);
  });

  // Приём гео — показываем координаты
  bot.onGeo([](VKMessage& msg) {
    bot.send(msg.peerId, "📍 " + String(msg.getLat(), 6) + ", " +
                          String(msg.getLon(), 6));
  });

  // Кнопка "ВКЛЮЧИТЬ" — старый API
  bot.processMessage("ВКЛЮЧИТЬ", [](long UserID, String text) {
    digitalWrite(LED_PIN, HIGH);
    bot.send(UserID, "🔛 Включено");
  });

  // Кнопка "ВЫКЛЮЧИТЬ" — старый API
  bot.processMessage("ВЫКЛЮЧИТЬ", [](long UserID, String text) {
    digitalWrite(LED_PIN, LOW);
    bot.send(UserID, "🔴 Выключено");
  });

  // Кнопка "СТАТУС" — новый API без параметров
  bot.onMessage("СТАТУС", []() {
    bot.sendToLast("📊 Система работает штатно");
  });

  // Кнопка "МЕНЮ" — новый API с VKMessage
  bot.onMessage("МЕНЮ", [](VKMessage& msg) {
    bot.sendWithKeyboard(msg.peerId, "Главное меню:", mainMenu);
  });

  Serial.println("✅ Бот запущен");
}

void loop() {
  bot.loop();
}
```

## ЧЕК ЛИСТ

   Если код не хочет работать, пройдитесь по этому списку.

### Серийный порт и питание

- **`Serial.begin(115200)`** — убедитесь, что в коде и в мониторе
  порта стоит **115200**.
- **Плата подключена к компьютеру** — проверьте кабель и COM-порт.
- **Внешнее питание** — если используете, проверьте напряжение (5В).
- **RESET** — иногда помогает перезагрузка кнопкой **RST** на плате.

### Wi-Fi

- **SSID и пароль** — соответствуют реальной сети.
- **Частота 2.4 ГГц** — ESP32 не работает на 5 ГГц.

### Токен и сообщество

- **Токен скопирован полностью** — без лишних пробелов и символов.
- **Бот включён**: Управление → Сообщения → Сообщения сообщества →
  Включены.
- **Long Poll API включён**: Управление → Работа с API → Long Poll API →
  Включено.
- **Типы событий**: в Long Poll API → Типы событий → отмечено
  **☑ Входящие сообщения**.
- **Вы подписаны** на сообщество, где находится бот.

### Код

- **Клавиатура создана** через `createKeyboard()`.
- **`bot.loop()`** вызывается в `void loop()`.
- **Создание объекта**: `VKassistent bot(Token, GroupID);` — переменная
  должна называться `bot`.
- **Отправка фото**: если используете, убедитесь, что у вас есть
  **пользовательский токен** (не токен сообщества).

## ЧАСТЫЕ ОШИБКИ

### Бот молчит, ничего не приходит

- Проверьте права токена (см. ЧЕК ЛИСТ → Токен и сообщество).
- Проверьте, что бот **включён** в настройках сообщества.
- Проверьте, что вы **подписаны** на сообщество.

### error_code: 15 — Access denied

- Для `photos.getMessagesUploadServer` нужен **пользовательский токен**.
- Токен сообщества **не подходит** для загрузки фото.

### Фото не сохраняется

- Проверьте `LittleFS.begin()` в начале — должно быть `✅ LittleFS OK`.
- Проверьте свободное место: `LittleFS.totalBytes() - LittleFS.usedBytes()`.
- Размер фото не должен превышать ~100 КБ.

### sendToLast не работает

- `sendToLast` работает **только внутри колбэка** (`onMessage`, `onPhoto` и т.д.).
- Если вызывать вне — будет `⚠️ sendToLast: вне колбэка`.

### Стикеры не отправляются

- VK **не позволяет** ботам сообществ отправлять стикеры.
- Это ограничение VK, не баг библиотеки.

### Команды срабатывают для всех пользователей

- Админы — это **список**, а не автоматическая защита.
- Чтобы ограничить команду — используйте `isAdmin()` в колбэке:
  ```cpp
  if (!bot.isAdmin(msg.fromId)) {
    bot.send(msg.peerId, "⛔ Нет прав");
    return;
  }
  ```

### Компиляция падает с «no member named...»

- Проверьте, что объект называется **`bot`**, а не `VKassistent`.
- Создание объекта должно быть: `VKassistent bot(Token, GroupID);`.
- Все методы вызываются через `bot.` (например, `bot.send(...)`).

## КРАТКИЙ СПРАВОЧНИК ПО API

   Все методы библиотеки с кратким пояснением.

### ПОДКЛЮЧЕНИЕ

```
VKassistent bot(Token, GroupID);
   Создаёт объект бота. Token — токен сообщества, GroupID — ID группы.

bot.connectWIFI(SSID, PASSWORD);
   Подключает ESP32 к Wi-Fi. Ждёт до 20 секунд.

bot.begin();
   Запускает бота: инициализирует LittleFS, получает Long Poll сервер.

bot.loop();
   Опрашивает VK и обрабатывает входящие. Вызывать в void loop().
```

### ХРАНИЛИЩЕ

```
bot.useLittleFS();
   Переключиться на внутреннюю память (по умолчанию).
   Все savePhoto / sendPhotoFromFS будут работать с ней.

bot.useSD(csPin);
   Переключиться на SD-карту. csPin — пин CS (например, 5).

bot.useSD(cs, sck, miso, mosi);
   То же, но с указанием всех пинов SPI.

После useSD() всё сохраняется на SD, fs в параметрах указывать не нужно.
```

### РЕГИСТРАЦИЯ КОМАНД

```
bot.processMessage("текст", cb);
   Старый API. Колбэк: cb(long userId, String text).

bot.onMessage("текст", cb);
   Новый API без параметров. Колбэк: cb().

bot.onMessage("текст", cb);
   Новый API с сообщением. Колбэк: cb(VKMessage& msg).
```

### ПРИЁМ ВЛОЖЕНИЙ

```
bot.onPhoto(cb);
   Срабатывает, когда пришло фото.

bot.onDoc(cb);
   Срабатывает, когда пришёл документ.

bot.onGeo(cb);
   Срабатывает, когда пришла гео-метка.

bot.onSticker(cb);
   Срабатывает, когда пришёл стикер.
```

### ОТПРАВКА СООБЩЕНИЙ

```
bot.send(peerId, text);
   Отправить текстовое сообщение.

bot.sendWithKeyboard(peerId, text, kb);
   Отправить сообщение с клавиатурой.

bot.sendToLast(text);
   Ответить в тот же чат. Только внутри колбэка.

bot.sendGeo(peerId, lat, lon);
   Отправить гео-метку без текста.

bot.sendGeo(peerId, text, lat, lon);
   То же, но с подписью.

bot.sendPhotoFromFS(peerId, path);
   Отправить фото из FS. Нужен пользовательский токен.

bot.sendPhotoFromFS(peerId, text, path);
   То же, но с подписью.
```

### СОХРАНЕНИЕ ВЛОЖЕНИЙ

```
bot.savePhoto(msg);
   Сохранить фото из сообщения. Возвращает путь или "".

bot.saveDoc(msg);
   Сохранить документ из сообщения. Возвращает путь или "".

bot.savePhotoAndReply(msg);
   Сохранить фото и сразу ответить в чат.

bot.saveDocAndReply(msg);
   То же для документа.
```

### КЛАВИАТУРЫ

```
String kb = createKeyboard(
  Button("ВКЛ", positive),
  Button("ВЫКЛ", negative),
  Line(),
  Button("СТАТУС", primary)
);
   Собирает JSON-клавиатуру. Кнопки автоматически по 5 в ряд.

Button("текст", цвет);
   Кнопка. Цвета: primary, secondary, positive, negative.

Line();
   Разрыв строки в клавиатуре.
```

### АДМИНЫ

```
bot.addAdmin(userId);
   Добавить пользователя в список админов.
   ВАЖНО: список не блокирует команды автоматически.

bot.isAdmin(userId);
   Проверить, является ли пользователь админом. Возвращает true/false.
   Используйте в колбэке для проверки прав.
```

### СТРУКТУРА VKMessage

```
msg.peerId          — ID чата (куда отвечать).
msg.fromId          — ID отправителя (кто написал).
msg.messageId       — ID сообщения.
msg.text            — Текст сообщения.
msg.attachments     — Массив вложений.

msg.hasPhoto()      — Есть ли фото.
msg.hasDoc()        — Есть ли документ.
msg.hasGeo()        — Есть ли гео.
msg.hasSticker()    — Есть ли стикер.

msg.getPhotoUrl()   — URL фото (максимальный размер).
msg.getDocUrl()     — URL документа.
msg.getDocTitle()   — Имя документа.
msg.getLat()        — Широта гео.
msg.getLon()        — Долгота гео.
```

### СТРУКТУРА VKAttachment

```
att.type            — "photo", "doc", "geo", "sticker".
att.url             — Ссылка на файл.
att.title           — Название (для doc).
att.id, att.ownerId — Идентификаторы вложения.
att.lat, att.lon    — Координаты (для geo).
```

## КОДЫ ОШИБОК VK

   Основные коды, которые может вернуть VK.

**5 — Неверный токен**
Токен просрочен или скопирован не полностью.
→ Пересоздайте токен в настройках сообщества.

**6 / 9 — Слишком много запросов**
Спам или частые вызовы `send()`.
→ Увеличьте паузу между сообщениями.

**15 — Нет прав**
У токена нет нужных галочек.
→ Для фото нужен пользовательский токен, не токен сообщества.

**27 — Неверный GroupID**
`GroupID` указан с минусом или как `club123`.
→ Только число: `123456789`.

**100 — Неверный параметр**
Пустой `message`, битая клавиатура или неверный `peer_id`.
→ Проверьте JSON клавиатуры и текст сообщения.

**113 — Неверный ID пользователя**
Пользователь не писал боту или `peerId` = 0.
→ Пользователь должен написать боту первым.

**121 — Битая строка photo**
`photo` испорчена при загрузке.
→ Файл должен быть настоящим JPEG (начинается с `FF D8`).

**901 / 902 — Приватность**
Пользователь запретил сообщения от сообществ.
→ Пользователь должен разрешить их в настройках VK.

**HTTP -1 — TLS не подключился**
Проблема с сетью или мало heap.
→ Проверьте Wi-Fi и `ESP.getFreeHeap()` (>50 КБ).

**HTTP -11 — Таймаут**
VK долго не отвечает.
→ Попробуйте позже, проверьте интернет.

**LittleFS mount failed (-84)**
Раздел повреждён.
→ `LittleFS.begin(true)` сам форматирует. Если не помогает —
Erase Flash → All Flash Contents.
